# 客户端开发

## 目录边界

- `app/page.tsx`：查看器界面与状态；`app/scene.tsx`：场景生命周期和交互调度。
- `app/core/`：解剖数据类型、分解布局、指针状态、模型解压和搜索工具。
- `app/rendering/`：材质着色器与可见索引批次。
- `client/platform/`：运行环境判断与外部链接桥接。
- `client/i18n/`：界面文案、术语草稿和生成来源。
- `client/content/`：中文阅读指南、方位词、常用骨骼说明、观察提示及搜索别名。
- `src-tauri/`：原生窗口、权限和安装配置。
- `public/models/`：原始网页资源；客户端构建只打包 gzip 模型，原始文件保持完整。
- `dist/` 与 `dist-client/`：分别为网页和客户端构建产物。

## Windows 构建

需要 Node.js 22.18+、Rust MSVC 工具链、Visual Studio C++ Build Tools 和 Windows SDK。依赖版本由 npm 与 Cargo 锁文件固定；检查脚本使用 Node 原生 TypeScript 支持。

```powershell
npm ci
npm run client:dev
# 生成当前用户安装的 NSIS 安装包
npm run client:build
```

产物位于 `src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis/`。需要 WebView2；安装程序在缺少运行时时使用联网引导程序。第一次 Rust 构建可能需要数分钟。仅在本机缓存完整且网络不可用时，可以在当前 PowerShell 进程设置 `$env:CARGO_NET_OFFLINE='true'`。

网页命令 `npm run dev` / `npm run build` 继续可用。原生窗口根据屏幕工作区限制初始大小；仅批准来源页面的 HTTPS 外链通过系统浏览器打开。

## 整体浏览操作

- 系统名称是标签；开关显示或隐藏该系统，“仅看”关闭其他系统并显示当前系统。
- “全部 / 骨骼 / 器官”切换图层组合；“当前图层”标明默认、预设、自定义、全部隐藏或单独查看结构的状态。手动开关组合若与预设一致，会自动显示对应预设。
- 选中结构即使所属系统已隐藏，也会临时显示，并在图层面板提示；切换图层组合会取消选择。
- 右侧“重置视角”恢复观察位置并停止自动旋转，保留图层、选择和分解程度；高分解程度使用正面视角。
- 底部“恢复全部”恢复默认图层与视角、取消选择、停止自动旋转，并将分解程度归零；默认图层不含体表。

## 结构搜索

搜索结果显示中文名、英文源名、包含的系统、人体左右、网格零件数和图谱源 ID。系统标签来自结果所包含零件的图层分组。左右优先依据源结构名；股骨等明确包含同名左、右零件的成对组合标为“左 / 右”，不会因器官包含左右子结构而给整个器官添加双侧标签。俗称命中时显示实际匹配词，例如“大腿骨”，便于对照“股骨”。左右以人体自身为准。

选择结果会高亮结构并打开详情。搜索框可清空；按 Escape 或点击“关闭搜索”退出。空搜索时将本次使用中最近查看的最多 6 个结构放在常用结构前，提供独立的清空入口；记录只保留在当前页面内存中，重新打开应用或刷新页面后清空。

## 结构详情与定位

详情面板随内容收紧；说明与观察提示优先展示，“源信息与零件”默认折叠。可收起详情以腾出观察空间，桌面可切换“加宽阅读 / 标准宽度”。收起详情保留选中结构与操作按钮。

- “定位到结构”：相机移向选中结构，保留当前图层和分解程度；周围结构可能遮挡目标，可配合“单独查看结构”。
- “单独查看结构 / 显示周围结构”：仅显示选中结构，或恢复当前图层组合；切换时将分解程度归零。
- “返回整体”：取消选择、退出单独查看并恢复整体视角，保留当前图层与分解程度。
- “关闭详情”：隐藏面板，保留选择；页面保留“查看详情”和“返回整体”入口。

处于定位或单独查看模式时，相机根据详情面板的实际尺寸为选中结构留出可见区域，折叠、加宽和展开源信息时会更新定位视角。

## 中文术语审校

`terms.zh-CN.json` 包含 5,090 个唯一源名称，覆盖模型零件和复合概念。中文名称是规则生成并补充常见词组的完整草稿，尚未经医学专家审校。源 ID、英文名称和模型归属保持不变。

审校时优先修改 `phrases.json` 的完整短语；词根规则在 `lexicon.txt`。随后运行：

```powershell
node scripts/generate-terms.mjs
npm run validate:locales
```

生成会覆盖术语 JSON，勿只修改生成文件而遗漏来源。`terms.metadata.json` 记录生成方法和草稿状态。切换语言不会重建 Three.js 场景；搜索始终支持中文、英文、源 ID。

中文用户可在“关于此图谱”查看阅读指南、方位词和参考链接。9 类常用骨骼的说明与观察提示在 `client/content/zh-CN.ts`，支持其左/右结构；其他结构继续显示已有器官说明或明确标注的系统概述。搜索别名独立于术语表维护，例如“大腿骨”“左大腿骨”“膝盖骨”，不会修改源名称或 ID。新增知识内容为基础学习说明，尚未经医学专家审校；事实核对来源在内容模块的 `CONTENT_REFERENCES`。

## 验证

```powershell
npm run ci:check
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
```

GitHub Actions 先在独立 Linux 任务运行 `ci:check`，通过后在 Windows 检查 Rust 格式并构建、上传测试安装包，不发布 Release。相同分支有新运行时取消旧运行。模型解压兼容原生 DecompressionStream 与 fflate 回退，拒绝截断和错误长度数据。

显隐变化会压紧对应批次的绘制索引，隐藏系统不提交三角形；隔离模式仅提交选中结构，分解视图的点标记也仅绘制可见零件。选中的隐藏系统零件仍按原有规则显示。索引只在批次可见集合变化时更新，分解动画不重复上传索引。为支持恢复显示，每个批次在 CPU 保留一份原始索引；切换系统减少绘制工作，但不释放已加载模型的显存。

CPU 调度按需运行：静止且相机阻尼结束后停止请求动画帧，交互、状态修改、窗口变化和分块加载会唤醒；页面隐藏时暂停。爆炸动画缓存可见零件集合与系统展开方向，仅更新可见零件的位置，选择纹理只在选择/显隐变化时上传。屏幕拾取范围在指针需要时计算并缓存，相机或位置变化后失效。

## 后续平台

macOS 需要在 macOS 上构建 DMG，并配置签名、公证及 Intel/Apple Silicon 验证。Android 需要 JDK、Android SDK/NDK，初始化 Tauri Android 工程，补充手机触控、返回键、生命周期与真实设备性能验证。当前未交付这两个平台安装包。
